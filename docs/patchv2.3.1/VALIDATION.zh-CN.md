## 使用

先关闭 EPSE 并备份旧文件夹，将 ZIP 解压得到的全部内容拖进原有 `EpseSingleV2.1` 文件夹，替换同名文件，再双击根目录 `OpenEPSE.exe`。无需额外安装 Java 或 Node.js。

补丁会替换两份数据库，旧版作答和成绩记录不会保留。本包需要完整 V2.1 原版，不能独立解压到空目录运行。
