EPSE V2.1 → V2.3.2-all 直接覆盖补丁
制作日期：2026-10-24

适用基础：完整的 Original\EpseSingleV2.1 原版。
目标版本：Modify\EpseSingleV2.3.2-all 当前完整功能版。

怎么用（不需要运行安装器）：
1. 先关闭所有 EPSE 窗口和后台。建议把新电脑上的 EpseSingleV2.1 整个文件夹备份一份。
2. 将本 ZIP 解压到一个临时文件夹。
3. 把解压得到的全部内容（epse、EpseDesktop、tools 及几个文件）一起拖进新电脑上
   原有的 EpseSingleV2.1 文件夹，遇到同名文件一律选择“替换目标中的文件”。
   也可以直接把 ZIP 解压到原 EpseSingleV2.1 文件夹并确认覆盖。
4. 双击该文件夹根目录的 OpenEPSE.exe 或 OpenEPSE.bat 启动。
   账号 / 密码：123456 / 123456。

正确层级示例：
  EpseSingleV2.1\OpenEPSE.exe
  EpseSingleV2.1\EpseDesktop\resources\app.asar
  EpseSingleV2.1\epse\epse-electron-2.0.0.jar
  EpseSingleV2.1\tools\reset-answers.ps1
不要在旧版文件夹里面再套一层补丁文件夹。
只把 ZIP 文件拖进去不会自动升级，必须解压并替换。

本补丁包含新版桌面逻辑、后端、题库数据库、前端、运行脚本、D 卷 v4 题库、
151 张新增配图及新版所带仿真数据，保留新版的 A/B/C/D 全部功能和已有修复。
与原版完全相同的 JRE、Electron 引擎及其他资源直接复用，因此它不是独立完整版，
不能单独解压到空文件夹运行。旧版中多余的语言包、源码映射等文件无需删除。

注意：为获得新版题库，补丁会替换 epse\config 下的两份数据库，旧版作答、成绩
等数据库记录不会保留。新版沿用启动和退出时清理作答的行为，覆盖前请先备份。
正常启动会自动重写本机数据库路径，无需保持原电脑的用户名、盘符或目录名；
不需要额外安装 Java、Node.js 或运行开发工具。请使用正常启动器，不要直接双击 JAR。
文件夹仍可叫 EpseSingleV2.1，功能由覆盖后的程序文件决定。

本补丁排除了原电脑的日志、进程 PID、Nginx 临时文件和初始数据库备份；
这些由程序在新电脑运行时按需生成。
补丁文件清单.json 记录新增/替换文件及全部目标运行文件的 SHA-256，供核对。
